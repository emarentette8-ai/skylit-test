# Event dataset (`events_primary.parquet`)

One row per ATM-band event for QQQ, SPY and SPXW. Built by `python3 -m study.build`; the full 50-symbol set (`results/cache/events.parquet`) is regenerated by the same command.

| Column group | Meaning |
|---|---|
| `event_id`, `cluster_id` | `symbol|date|K|entry bar|level`; impulse cluster = same symbol/day/direction, entries <= 5 min apart |
| `level` | `real` (listed strike) or `placebo` (midpoint between listed strikes) |
| `event` | `entry` (first close inside +/-b after an armed exterior close) or `jump` (band skipped) |
| `t_entry_bar`, `tau` | minutes since 09:30 ET of the entry bar and of the decision (= bar + 1) |
| `decision_time_utc`, `decision_time_et` | decision timestamp |
| `s` | frozen approach direction: +1 from below, -1 from above |
| `eligible` | 1 if a gamma snapshot <= tau exists and the level is listed in it |
| `f_*` | pre-decision features (closes <= entry bar, snapshot <= tau); see `study/build.py` |
| `y_*` | outcomes from the executable entry `y_p0` (open of bar tau); returns in % of raw price, direction-adjusted by `s` |
| `split` | dev (Jul), val (Aug), holdout (Sep) |

`net_gamma` from Skylit is vendor-estimated exposure netted over the nearest 5 expirations; it is not dealer inventory. Data: Skylit.
